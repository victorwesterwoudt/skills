Before evaluating any design, ask: **does this need more — or does it need less?**

## The anti-pattern to call out

The most common design mistake: adding more (colors, shadows, decorations, elements) to fix a design that needs subtraction. When something feels off, the instinct is to decorate. That instinct is wrong.

**Remove before you add.** If you strip one element and the design improves, you found the problem. If it doesn't, try the next element. Addition is almost never the answer to a design that feels broken.

## Core principles

**1. Visual hierarchy first** — Every layout needs a single dominant element. The eye needs an anchor before it can move. If everything is the same size, nothing is important. Set one thing as the clear focus; let everything else serve it.

**2. Spacing is design** — White space is not empty space. Generous, consistent spacing signals confidence and makes content breathe. Tight spacing signals anxiety. When in doubt, add more space than feels comfortable — then add 25% more.

**3. Contrast does the heavy lifting** — Size, weight, and color contrast establish hierarchy without decoration. A 12px body and 32px heading communicate more than any color scheme. Build hierarchy with contrast before reaching for color.

**4. Alignment creates calm** — Misaligned elements create visual tension even when viewers can't name it. Everything aligns to a grid or to each other — not "approximately." Implied grids are as powerful as explicit ones.

**5. Color: restraint over variety** — One or two accent colors maximum. Neutrals carry the layout. Color draws the eye — deploy it only where attention is warranted.

**6. Typography is 80% of UI** — Get type scale, weight contrast, and line-height right and most layouts work. Typography mistakes — tight line-height, wrong weight pairings, too many sizes — are the most common source of "something feels off."

## Design review checklist

Before shipping any UI, work through these in order:

1. **Hierarchy** — Is there a clear focal point? Can you tell what's most important at a glance?
2. **Spacing** — Is spacing consistent and generous? Does the layout breathe?
3. **Typography** — Does the type scale communicate content structure? Are weight contrasts clear?
4. **Color** — Is color being used intentionally, not decoratively? Could you remove one color and improve the design?
5. **Subtraction** — Does anything need to be removed? What is the weakest element on screen?

Fix in this order. Hierarchy problems make color problems invisible. Resolve hierarchy first.

## Quick-reference: what to try when something feels wrong

| Feels wrong | Try this first |
|---|---|
| Cluttered / busy | Remove one element; increase padding or spacing |
| Flat / boring | Add weight contrast (not color) — larger heading, bolder key text |
| Unbalanced | Align everything to an implicit grid |
| Too many colors | Strip to neutral palette + one accent |
| Looks amateurish | Increase font size contrast between heading and body |
| Heavy / dense | Increase line-height and section padding |
| Disconnected sections | Share a consistent spacing unit across all sections |
| Buttons look weak | Increase font weight or horizontal padding — not color |

## Giving feedback

Name the specific problem before the fix. Work through the checklist in order. Never suggest adding until subtraction has been tried.
